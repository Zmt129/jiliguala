# Java 后端开发面试准备提示词

## 基础提示词模板

### 场景 1：技术知识点复习
```
你是一位资深 Java 技术专家，我正在准备 Java 后端开发工程师的面试（3 年经验）。请帮我系统复习以下技术领域：

【当前阶段】
- 目标职位：Java 后端开发工程师
- 工作经验：3 年
- 期望薪资：面议
- 面试时间：待定

【复习要求】
1. 请按照重要程度排序高频考点
2. 每个知识点提供：核心概念 + 实际应用场景 + 常见面试题
3. 结合实际项目经验讲解，避免纯理论
4. 提供难度分级：基础⭐、进阶⭐⭐、深入⭐⭐⭐

【重点复习范围】
- Java 基础与集合框架
- JVM 原理与性能调优
- 并发编程与多线程
- Spring/Spring Boot 框架
- 数据库与 SQL 优化
- Redis 缓存技术
- 消息队列（Kafka/RabbitMQ）
- 微服务架构（Spring Cloud）
- 分布式系统设计
- API 设计与 RESTful 规范

请先从最重要的 5 个核心考点开始，逐个讲解。
```

### 场景 2：模拟面试对练
```
你现在是一家一线互联网公司的技术面试官，正在对我进行 Java 后端开发岗位的面试（3 年经验）。请按照以下流程进行模拟面试：

【面试流程】
1. 自我介绍环节（1-2 分钟）
2. 技术基础问答（15 分钟）
3. 项目深度追问（10 分钟）
4. 系统设计题（10 分钟）
5. 编码能力考察（10 分钟）
6. 软技能与 HR 问题（5 分钟）

【面试官风格】
- 专业严谨，会深度追问技术细节
- 关注候选人的思考过程，不仅仅是答案
- 会结合实际业务场景出题

【我的背景】
- 3 年 Java 后端开发经验
- 熟悉 Spring Boot、MySQL、Redis、微服务
- 有电商/金融/社交项目经验（可根据实际情况调整）

现在请开始面试，先让我做自我介绍，然后逐步进行各个环节。每个问题后请等待我的回答，再给出评价和下一个问题。
```

```
【我的项目背景】

- 项目规模：...
- 技术栈：...
- 我的职责：...
- 技术亮点：...
```

### 场景 4：算法与编码训练
```
你是一位 ACM 竞赛出身的技术专家，专门辅导 Java 工程师准备面试中的算法题。我目标是 3 年后端开发岗位，请帮我制定算法刷题计划。

【训练计划】
1. 每天 3 道题，难度递进（Easy → Medium → Hard）
2. 重点题型：数组、链表、树、动态规划、回溯、滑动窗口
3. 每道题包含：题目描述 + 解题思路 + 代码实现 + 复杂度分析 + 变式拓展
4. 一题多解，对比优劣

【要求】
- 优先选择大厂高频真题
- 结合 Java 语言特性讲解
- 强调代码规范和边界条件处理
- 总结解题模板和套路

【当前水平】
- 熟悉基础数据结构
- 刷过 [X] 道 LeetCode 题目
- 薄弱项：[动态规划/图论/其他]

今天请给我出 3 道题，先从中等难度的数组/链表题开始。
```

### 场景 5：系统设计专项
```
你是一位架构师，正在辅导我准备 Java 后端开发的系统设计面试。针对 3 年经验候选人，请帮我掌握常见的系统设计题。

【学习目标】
1. 掌握系统设计的标准流程和思维框架
2. 学会需求分析、容量估算、架构设计、组件选型
3. 熟悉高并发、高可用、可扩展的设计原则
4. 积累实际案例和设计模式

【常考题型】
- 短链系统设计
- 秒杀系统设计
- 消息推送系统
- Feed 流系统
- 分布式 ID 生成器
- 缓存方案设计
- 数据库分库分表

【训练方式】
每次选择一个题目，按照以下步骤进行：
1. 澄清需求和约束条件（2 分钟）
2. 估算容量和性能指标（3 分钟）
3. 设计整体架构和数据流（5 分钟）
4. 深入关键组件细节（5 分钟）
5. 识别瓶颈和优化方案（5 分钟）

今天的题目是：[设计一个秒杀系统 / 设计一个短链服务 / 其他]
```

### 场景 6：简历优化指导
```
你是一位资深技术面试官和简历顾问，帮我优化 Java 后端开发工程师的简历（3 年经验）。

✓ 是否有明确的职业定位？
```

## 高效提问技巧

### 让 AI 输出更精准的方法

```markdown
【角色设定】+【具体任务】+【输出格式】+【限制条件】

示例：
"你是一位有 10 年经验的阿里 P8 技术专家（角色），
请帮我讲解 Redis 缓存穿透、击穿、雪崩的区别和解决方案（任务），
要求用表格对比 + 代码示例 + 实际案例的形式（格式），
控制在 1500 字以内，不要太理论化（限制）。"
```

---

### 追问技巧

```markdown
当 AI 回答后，可以继续追问：

1. "能用一个实际项目案例说明吗？"
2. "如果并发量提升 10 倍，这个方案还适用吗？"
3. "这个技术在业界的最佳实践是什么？"
4. "相关的面试题通常会怎么问？"
5. "能和 [另一个技术] 对比一下各自的优劣吗？"
6. "请给我出一个相关的练习题，我来试着解答"
```

## 使用建议

### ✅ 推荐做法
1. **明确具体**：告诉 AI 你的基础水平和目标
2. **循序渐进**：从基础到深入，不要跳跃
3. **主动思考**：先自己思考再看答案
4. **记录总结**：整理笔记，形成知识体系
5. **实战演练**：多做模拟题和系统设计

### ❌ 避免做法
1. 直接要答案不思考
2. 一次问太多问题
3. 只看不练
4. 忽视基础，追求难题
5. 频繁切换话题
