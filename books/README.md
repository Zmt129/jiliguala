## 这是什么

这里是 `books/` 文档库，用来集中存放项目相关的说明、规范、安装手册、设计稿与任务拆解等 Markdown 文档。

## 目录结构

- `specs/`：专题规格说明（需求、设计、数据结构、任务等）
- `ai-md/`：你让 AI（我）写的 Markdown 内容（会按主题归档，并在索引里列出来）

## 我该从哪里开始看

- 如果你要做某个功能：先看 `specs/` 里对应专题的 `requirements.md`（需求）和 `design.md`（设计）
- 如果你是要找“我让你写的那篇文档”：去 `ai-md/index.md` 按标题找

## 约定（为了你好找）

- 文件名尽量用英文短横线，例如：`login-flow.md`、`privacy-summary.md`
- 每篇文档开头都包含：**背景/目标**、**适用范围**、**结论或步骤**
- 你只要对我说“写一篇关于 XXX 的文档”，我会：
  - 先补齐你没说清的点（我会用非常简单的问题帮你补）
  - 写成 Markdown
  - 放进 `ai-md/` 并更新 `ai-md/index.md`
