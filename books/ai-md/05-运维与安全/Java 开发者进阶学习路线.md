## 1. 技术栈学习路线

### 🌱 初级阶段（0-2 年）

#### 核心基础

**Java 基础**
- ✅ Java 语法基础（数据类型、流程控制、数组）
- ✅ 面向对象（封装、继承、多态、抽象类、接口）
- ✅ 常用 API（String、Date、Math、System）
- ✅ 集合框架（List、Set、Map、HashMap 源码分析）
- ✅ 异常处理（Exception、Error、自定义异常）
- ✅ IO/NIO（文件操作、序列化）
- ✅ 反射机制（Class、Field、Method）
- ✅ 注解（Annotation、元注解、自定义注解）
- ✅ 泛型（类型参数、通配符、类型擦除）
- ✅ 枚举（Enum、枚举方法）

**推荐书籍：**
- 《Java 核心技术卷 I》
- 《Effective Java》（至少读 3 遍）
- 《Java 编程思想》

**JVM 基础**
- ✅ 内存模型（堆、栈、方法区）
- ✅ 垃圾回收机制（GC 算法、垃圾收集器）
- ✅ 类加载机制（双亲委派模型）
- ✅ JVM 参数调优基础
- ✅ 使用工具：jstat、jmap、jstack、VisualVM

**数据库基础**
- ✅ SQL 语法（CRUD、JOIN、子查询）
- ✅ 索引原理（B+ 树、聚簇索引、覆盖索引）
- ✅ 事务隔离级别（读未提交、读已提交、可重复读、串行化）
- ✅ 锁机制（行锁、表锁、间隙锁）
- ✅ MySQL 性能优化（EXPLAIN 分析、慢查询日志）
- ✅ 数据库设计三范式
- ✅ Redis 基础（数据类型、持久化、主从复制）

**框架基础**
- ✅ Spring（IOC、AOP、Bean 生命周期）
- ✅ Spring MVC（请求流程、拦截器、异常处理）
- ✅ MyBatis（映射文件、动态 SQL、缓存机制）
- ✅ Spring Boot（自动配置、Starter、Profile）
- ✅ Maven/Gradle（依赖管理、构建配置）

**前端基础（了解即可）**
- ✅ HTML/CSS/JavaScript 基础
- ✅ Ajax、JSON
- ✅ Vue/React 基础概念
- ✅ RESTful API 设计规范

#### 实战项目建议

**练手项目：**
1. 博客系统（包含用户、文章、评论、标签）
2. 在线商城（商品、购物车、订单、支付）
3. 图书管理系统（借阅、归还、预约）
4. 任务管理系统（CRUD、权限控制）

**目标：**
- 独立完成一个完整的项目
- 理解 MVC 分层架构
- 掌握基本的 CRUD 操作
- 学会使用 Git 进行版本控制

### 🌿 中级阶段（2-5 年）

#### 深入理解

**并发编程**
- ✅ 线程基础（Thread、Runnable、Callable）
- ✅ 线程池（ThreadPoolExecutor、Executors）
- ✅ 锁机制（synchronized、ReentrantLock、ReadWriteLock）
- ✅ volatile 关键字（可见性、有序性、禁止指令重排）
- ✅ CAS 与原子类（AtomicInteger、AtomicReference）
- ✅ AQS（AbstractQueuedSynchronizer 源码分析）
- ✅ ConcurrentHashMap 原理
- ✅ ThreadLocal 原理与内存泄漏
- ✅ CompletableFuture 异步编程
- ✅ Fork/Join 框架
- ✅ 并发工具类（CountDownLatch、CyclicBarrier、Semaphore）

**推荐书籍：**
- 《Java 并发编程实战》（必读经典）
- 《深入理解 Java 虚拟机》（周志明）

**JVM 深入**
- ✅ GC 日志分析
- ✅ OOM 问题排查与解决
- ✅ CPU 100% 问题定位
- ✅ 字节码增强（ASM、Javassist）
- ✅ JIT 编译优化
- ✅ Arthas 在线诊断工具

**分布式基础**
- ✅ CAP 定理、BASE 理论
- ✅ 一致性哈希算法
- ✅ RPC 原理（Dubbo、gRPC）
- ✅ HTTP/HTTPS 协议深入
- ✅ TCP/IP 协议基础
- ✅ 负载均衡算法（轮询、加权轮询、最少连接数）

**消息队列**
- ✅ Kafka（架构、分区、副本、Exactly Once）
- ✅ RabbitMQ（Exchange、Queue、Routing）
- ✅ RocketMQ（事务消息、顺序消息）
- ✅ 消息丢失、重复消费、积压问题解决

**搜索引擎**
- ✅ Elasticsearch 基础（Index、Document、Mapping）
- ✅ 倒排索引原理
- ✅ 分词器、 Analyzer
- ✅ 聚合查询、全文检索

**微服务基础**
- ✅ Spring Cloud Alibaba 生态
- ✅ Nacos（注册中心、配置中心）
- ✅ Sentinel（限流、熔断、降级）
- ✅ Seata（分布式事务）
- ✅ Gateway（网关、路由、过滤器）
- ✅ OpenFeign（声明式调用）

**容器化**
- ✅ Docker（镜像、容器、Dockerfile）
- ✅ Docker Compose
- ✅ Kubernetes 基础概念（Pod、Service、Deployment）

#### 实战项目建议

**进阶项目：**
1. 秒杀系统（高并发、库存扣减、限流）
2. 短链接系统（分布式 ID、缓存、数据库分表）
3. 分布式文件系统（文件上传、断点续传）
4. IM 即时通讯（WebSocket、消息推送）
5. 数据同步系统（CDC、 Canal、数据一致性）

**目标：**
- 能够设计高可用系统
- 解决复杂的并发问题
- 理解分布式系统挑战
- 具备性能优化能力

### 🌳 高级阶段（5 年以上）

#### 架构思维

**系统设计**
- ✅ DDD 领域驱动设计（实体、值对象、聚合根、限界上下文）
- ✅ 微服务拆分原则（单一职责、高内聚低耦合）
- ✅ 事件驱动架构（Event Sourcing、CQRS）
- ✅ Saga 模式、TCC 分布式事务
- ✅ 最终一致性方案
- ✅ 读写分离、CQRS
- ✅ 分库分表策略（ShardingSphere）
- ✅ 多级缓存架构（本地缓存 + 分布式缓存）
- ✅ CDN 加速、动静分离

**高可用架构**
- ✅ 限流算法（令牌桶、漏桶、滑动窗口）
- ✅ 熔断降级策略
- ✅ 故障转移、故障恢复
- ✅ 灰度发布、蓝绿部署、金丝雀发布
- ✅ 监控告警体系（Prometheus、Grafana）
- ✅ 链路追踪（SkyWalking、Zipkin）
- ✅ 日志聚合（ELK Stack）

**性能优化**
- ✅ 全链路压测（JMeter、Gatling）
- ✅ 性能瓶颈分析（APM 工具）
- ✅ 数据库优化（SQL 调优、索引优化、分库分表）
- ✅ JVM 调优实战
- ✅ 网络优化（TCP 参数、HTTP 优化）
- ✅ 缓存穿透、击穿、雪崩综合解决方案

**安全架构**
- ✅ OAuth2.0、OIDC、SAML
- ✅ JWT 深入（签名、加密、刷新机制）
- ✅ RBAC、ABAC 权限模型
- ✅ 数据加密（对称加密、非对称加密、国密算法）
- ✅ 防重放攻击、防篡改
- ✅ 敏感数据脱敏
- ✅ 安全审计

**大数据相关**
- ✅ Hadoop 生态（HDFS、MapReduce、YARN）
- ✅ Spark（RDD、DataFrame、SparkSQL）
- ✅ Flink（流处理、状态管理、时间语义）
- ✅ Hive、HBase
- ✅ ClickHouse（OLAP 分析）
- ✅ Data Lake（数据湖）

#### 实战项目建议

**架构级项目：**
1. 电商平台整体架构设计（微服务拆分、中台建设）
2. 金融支付系统（资金安全、对账、风控）
3. 物流跟踪系统（海量数据、实时计算）
4. 社交推荐系统（用户画像、推荐算法）
5. 监控平台（指标采集、告警、可视化）

**目标：**
- 具备大型系统架构设计能力
- 能够做技术选型和决策
- 平衡业务需求和技术债务
- 带领团队完成复杂项目

## 2. 软技能培养

### 💡 沟通能力

**为什么重要：**
- 70% 的问题源于沟通不畅
- 好的沟通能减少返工
- 影响力 = 技术能力 × 沟通能力

**如何提升：**
- ✅ 学会倾听（不要急于反驳）
- ✅ 结构化表达（结论先行、分点论述）
- ✅ 写技术文档（README、设计文档、总结）
- ✅ 技术分享（团队内部分享、技术大会演讲）
- ✅ 学会提问（描述背景、已尝试方案、期望结果）

**推荐书籍：**
- 《非暴力沟通》
- 《金字塔原理》

### 🎯 时间管理

**四象限法则：**
```
         紧急        不紧急
重要   | 救火     | 规划     |
       | 马上做   | 计划做   |
---------------------------
不重要 | 干扰     | 浪费     |
       | 授权做   | 尽量不做 |
```

**实践方法：**
- ✅ 待办事项清单（TODO List）
- ✅ 番茄工作法（25 分钟专注 + 5 分钟休息）
- ✅ GTD（Getting Things Done）
- ✅ 每天保留 2 小时深度工作时间
- ✅ 学会说"不"（不是所有需求都要接）

### 🤝 团队协作

**Git 协作规范：**
```bash
# 分支管理
main/master    # 生产分支
develop        # 开发分支
feature/*      # 功能分支
release/*      # 发布分支
hotfix/*       # 热修复分支

# Commit 规范
feat: 新功能
fix: 修复 bug
docs: 文档更新
style: 代码格式调整
refactor: 重构
test: 测试用例
chore: 构建工具或依赖更新
```

**Code Review 文化：**
- ✅ 尊重他人代码
- ✅ 对事不对人
- ✅ 提出建设性意见
- ✅ 接受批评和建议
- ✅ 及时回复 review 意见

### 📚 学习能力

**费曼学习法：**
1. 选择一个概念
2. 假装教给别人
3. 卡壳时回去学习
4. 简化语言，用类比

**主题式学习：**
- 确定一个主题（如"分布式事务"）
- 收集相关资料（书籍、博客、视频）
- 系统性学习（1-2 个月专注一个主题）
- 输出总结（博客、笔记、分享）

**建立知识体系：**
```
              Java 核心
                 |
    -------------------------
    |           |           |
  JVM        并发编程      框架
    |           |           |
    -------------------------
                 |
            分布式系统
                 |
    -------------------------
    |           |           |
  消息队列     缓存       数据库
```

### 🧠 问题解决能力

**调试技巧：**
- ✅ 复现问题（最小可复现场景）
- ✅ 二分法定位（缩小问题范围）
- ✅ 对比法（和正常情况对比）
- ✅ 假设验证（提出假设→设计实验→验证）
- ✅ 橡皮鸭调试法（向别人解释问题）

**排查思路：**
```
1. 明确问题现象
2. 收集相关信息（日志、监控、配置）
3. 提出可能原因
4. 逐一验证
5. 定位根本原因
6. 制定解决方案
7. 实施并验证
8. 总结复盘
```

## 4. 项目实战建议

### 🎯 如何挑选项目

**好的项目特征：**
- ✅ 有明确的业务场景
- ✅ 技术栈匹配当前水平略有挑战
- ✅ 可以持续迭代优化
- ✅ 有真实用户或使用场景
- ✅ 代码可以开源分享

**避免的坑：**
- ❌ 纯 CRUD 没有技术含量
- ❌ 过于简单几天就做完
- ❌ 技术太新没有参考资料
- ❌ 闭门造车不考虑实际需求

### 📋 项目开发流程

**1. 需求分析**
```
- 用户是谁？
- 解决什么问题？
- 核心功能有哪些？
- 性能要求如何？
- 预期用户量多少？
```

**2. 技术选型**
```
- 后端框架：Spring Boot / Quarkus
- 数据库：MySQL / PostgreSQL
- 缓存：Redis / Caffeine
- 消息队列：Kafka / RocketMQ
- 部署方式：Docker / K8s
```

**3. 架构设计**
```
- 系统分层（Controller、Service、Repository）
- 模块划分（用户模块、订单模块...）
- 数据库设计（ER 图、表结构）
- API 设计（RESTful 接口定义）
```

**4. 编码实现**
```
- 搭建项目骨架
- 实现核心业务逻辑
- 编写单元测试
- 代码 Review
- 持续重构优化
```

**5. 测试部署**
```
- 单元测试覆盖率 > 80%
- 集成测试
- 性能测试
- CI/CD 流水线
- 监控告警配置
```

### 🏆 值得做的项目类型

**业务系统类：**
1. 电商系统（完整闭环，涉及面广）
2. 在线教育平台（直播、录播、互动）
3. 社交应用（IM、动态、关注）
4. 金融科技系统（支付、理财、风控）

**技术挑战类：**
1. 高并发秒杀（限流、缓存、队列）
2. 海量数据处理（分库分表、ES）
3. 实时数据同步（CDC、Flink）
4. 分布式任务调度（XXL-JOB 类似）

**中间件类：**
1. 实现一个简单的 RPC 框架
2. 实现一个简易版 Tomcat
3. 实现一个数据库连接池
4. 实现一个分布式 ID 生成器

**工具类：**
1. 代码生成器
2. 数据迁移工具
3. 日志分析工具
4. 性能监控 Agent

## 5. 职业规划与发展

### 🗺️ 职业发展路径

```
初级工程师（0-2 年）
    ↓
中级工程师（2-5 年）
    ↓
高级工程师（5-8 年）
    ↓
技术专家 / 架构师（8-10 年）
    ↓
CTO / 技术副总裁（10 年+）
```

### 🎯 不同阶段的重点

**初级 → 中级**
- 技术深度：精通一门语言，深入理解框架原理
- 独立负责：能独立完成模块开发
- 解决问题：具备独立排查问题的能力

**中级 → 高级**
- 技术广度：了解整个技术栈，能做技术选型
- 系统设计：具备中型系统设计能力
- 带新人：指导初级工程师成长

**高级 → 专家/架构师**
- 架构能力：大型系统架构设计
- 技术前瞻：把握技术趋势，提前布局
- 影响力：行业知名度，技术布道

### 💼 面试准备

**简历要点：**
- ✅ 突出技术亮点（解决了什么难题）
- ✅ 量化成果（性能提升 X%，支撑 QPS 达到 X）
- ✅ 项目描述 STAR 法则（Situation、Task、Action、Result）
- ✅ 技术栈清晰列出（熟练程度分级）
- ✅ 开源项目、博客、专利加分项

**面试常见问题：**
- Java 基础（集合、并发、JVM）
- 框架原理（Spring、MyBatis 源码）
- 数据库（索引、事务、锁、优化）
- 分布式（缓存、MQ、RPC、一致性）
- 系统设计（现场设计一个系统）
- 项目深挖（遇到的挑战、如何解决）

**谈薪技巧：**
- 了解市场行情（Boss 直聘、拉勾查薪资范围）
- 基于自身价值（能力 + 贡献）
- 综合考虑（薪资、股票、福利、发展空间）
- 不要只为了钱跳槽（成长性更重要）

## 6. 保持竞争力的秘诀

### 🔄 持续学习

**技术更新快怎么办？**
- 打好坚实基础（底层原理不变）
- 关注核心本质（新技术是旧技术的演进）
- 保持好奇心（每周了解新技术）
- 建立学习体系（主题式学习）

**学习时间哪里来？**
- 早起 1 小时（黄金学习时间）
- 通勤时间（听播客、看文章）
- 周末半天（深度学习）
- 工作中学习（把每个任务当学习机会）

### 🔥 保持激情

**职业倦怠怎么办？**
- 设定阶段性目标（每半年一个小目标）
- 寻找志同道合的伙伴（技术圈子）
- 参加技术大会（感受行业氛围）
- 做有挑战性的项目（跳出舒适区）
- 帮助他人成长（教学相长）

**35 岁危机真的存在吗？**
- 技术更新快，但经验更宝贵
- 转型管理 or 深耕技术（两条路都可以）
- 建立个人品牌（技术影响力）
- 保持学习能力（年龄只是数字）

### 🌟 建立个人品牌

**技术博客：**
- 坚持写作（每月至少 2 篇）
- 保证质量（深度思考，不是流水账）
- 形成系列（专题文章更容易被记住）
- 多平台分发（掘金、思否、公众号）

**开源贡献：**
- 从小的 PR 开始（修复 typo、完善文档）
- 参与知名项目（增加曝光度）
- 维护自己的项目（展示能力）
- 写清楚 README（降低参与门槛）

**技术分享：**
- 团队内部分享（锻炼表达能力）
- 技术沙龙演讲（扩大影响力）
- 线上直播分享（触达更多人）
- 录制视频课程（被动收入）

**社交媒体：**
- GitHub（代码作品集）
- 知乎（专业问答）
- Twitter/微博（行业动态）
- LinkedIn（职业网络）

### ⚖️ 工作生活平衡

**健康第一：**
- 规律作息（尽量不熬夜）
- 坚持运动（每周至少 3 次）
- 注意坐姿（人体工学椅、升降桌）
- 定期体检（关注身体状况）

**家庭关系：**
- 陪伴家人（放下手机，高质量陪伴）
- 获得支持（让家人理解你的工作）
- 分担家务（不要当甩手掌柜）

**兴趣爱好：**
- 培养工作外的兴趣（音乐、阅读、旅行）
- 结交不同圈子的朋友（拓宽视野）
- 给自己留白（独处思考的时间）
